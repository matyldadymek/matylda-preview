# matylda-preview

Preview copy of www.matyldadymek.co.uk – changes are tried here first.

- Preview address: https://matyldadymek.github.io/matylda-preview/ (hidden from Google, marked PREVIEW)
- Live site: repository **matylda-site**

When a change is approved, it is copied to matylda-site. Lines marked `<!-- preview-only -->` are not copied. Content you edit on the live site (Pages CMS) is copied here first, so nothing you change there gets overwritten.
